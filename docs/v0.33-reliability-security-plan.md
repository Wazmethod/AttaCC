## Important security distinction

Checking the `network`, `origin`, command age and message shape is a **sanity check**, not network authentication. Any nearby computer able to transmit modem messages could forge these values. For Minecraft gameplay this is often an acceptable starting point, but we must not claim it authenticates senders. Do not treat modem-transmitted origin strings as secret or trusted.

For sensitive commands, consider an explicit per-world shared secret or a pairing workflow in a separate, opt-in change if playtesting indicates a need.

## Tests on a spare SteamPlant / Master setup

1. Run a valid remote command and confirm the Master receives the same result as before.
2. Disconnect the wireless modem and reconnect it; ensure handlers recover.
3. Test stale timestamps and wrong network through the optional validator before connecting it to a live handler.
4. Try an invalid package path from a test manifest; it must be rejected without overwriting protected files.
5. Update a normal app/module with `pkgctl update` to verify the existing package format remains compatible.

Avoid testing safety commands against an important live contraption. No dedicated test-suite execution has been performed in the game yet.
