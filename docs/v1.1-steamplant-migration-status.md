# SteamPlant — AttaCC SDK V1.1

## Statut de conversion des sources

**Bascule des sources réalisée sur `feature/v1.1-sdk-unification`.**
Le package `app.steamplant` est déclaré `sdkNative=true` et ne
contient plus aucune destination ni module métier historique.
Il n'y a **pas de chemin d'exécution legacy** dans SteamPlant.

Le chemin canonique `apps/steamplant/` contient uniquement :

- `main.lua` : composition SDK, données, contrôles, vues et cycle de vie
- `config.lua` : paramètres par défaut propres à l'application
- `requirements.lua` : contrat des périphériques
- `controller.lua` : machine d'états, sécurités et commandes métier
- `outputs.lua` : moteur, embrayages et état des sorties via SDK
- `telemetry.lua` : relevés et métriques via SDK

Les entrées et copies antérieures (`steamplant.lua`, `modules/steamplant.lua`,
`lib/controller.lua`, `lib/io.lua`, `lib/config.lua`, etc.) ne sont
plus livrées par `app.steamplant`. Les anciennes sources SteamPlant
ont été supprimées de cette branche.

## Démarrage natif

L'installation est gérée par le manifeste et `pkgctl` :

```text
pkgctl install preset.steamplant
pkgctl activate preset.steamplant
pkgctl run steamplant
```

Le démarrage automatique CraftOS se fait **uniquement** par
`startup.lua` → `appctl.lua steamplant` → `apps/steamplant/main.lua`.
Les périphériques sont configurés via `ioctl init` puis contrôlés par
`ioctl check`. Les paramètres SDK propres à SteamPlant sont surchargés
par `/etc/attacc/apps/steamplant/config.lua` ; aucune ancienne
configuration ou sauvegarde SteamPlant n'est importée.

## Contrats vérifiables lors de l'audit

La conversion implémente les services suivants :

- `app:requirements()`, `app:config()`, `app:state()`
- `app:output()`, `app:call()`, `app:read()`
- `app:data()`, `app:graph()`, `app:control()`, `app:view()`
- `app:lifecycle()`, géré par le runtime générique
- transport SDK et autorisation des commandes à distance

Les tests de contrat disponibles dans `tests/` :
`steamplant-controller-sdk.lua`, `steamplant-outputs-sdk.lua`,
`steamplant-telemetry-sdk.lua`.

## Limite importante — audit et validation requis

**La conversion des sources n'équivaut pas à une homologation de la centrale.**
Aucun de ces tests n'a été exécuté sur un ordinateur CC:Tweaked dans
cette session. Avant toute mise en production, l'audit devra vérifier
la syntaxe Lua et les appels SDK, l'ordre de restauration des sorties,
les interlocks, les défauts matériels, les transitions et les délais,
les autorisations et signatures réseau, le rendu et les touches
sur moniteur, ainsi que les scénarios de redémarrage.

Ne pas déployer cette branche sur une centrale active avant ces vérifications.
Les autres applications AttaCC (Master, Pocket, etc.) ont leur propre
migration et ne sont pas déclarées natives par cette conversion.
